# Install N3 Manual — English

[English](INSTALL.en.md) / [Polski](INSTALL.pl.md)

Download **N3Manual-1.0.0-beta2.apk** from the
[release](https://github.com/staszczykgrzegorz-zoltar1004/DJI-Goggles-N3-MANUAL-USB/releases/tag/v1.0.0-beta2).
Open the APK on your Android phone and allow your file manager/browser to
install it when Android asks. USB debugging, a PC and root are unnecessary.

One APK contains both languages. Android's installer and USB permission dialogs
use Android's language. The app initially uses Polish on a phone whose primary
system language is Polish, and English otherwise. At the top of the application,
tap **Language / Język** and select **System (automatic)**, **English** or
**Polski**. Android 13+ also offers this choice in the app's system settings.
On Android 6–12 the app remembers the choice locally.

Public beta1 can be updated directly to beta2 with this APK. Private0.1–0.3
prototypes used a different signature and must be uninstalled once first.

On the bench, with propellers removed and motors off, power on N3, Neo and FPV
RC3 and keep their radio link. Close DJI Fly. Connect the phone to the goggles
only, using a USB data cable. Select N3 Manual for USB and grant permission.

Tap **Connect and test USB**, then **1. Go to Manual** after confirming bench
preparation. Look inside the goggles. Tap **2. I see Confirm — accept** only
when the selected right-hand button actually says **Confirm**. If Manual is
already selected, no new confirmation is needed. Verify the checkmark in the
goggles. Disconnect the phone before flight.

Changing language cancels pending work and clears Confirm. Reconnect/test USB
afterwards. The app language does not change the goggles menu language or
expand supported hardware. The application does not patch firmware or freeze M.
