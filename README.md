# N3 Manual — English / Polski

**[English instructions](README.en.md) · [Instrukcja po polsku](README.pl.md)**

**[Download APK / Pobierz APK — 1.0.0-beta2](https://github.com/staszczykgrzegorz-zoltar1004/DJI-Goggles-N3-MANUAL-USB/releases/tag/v1.0.0-beta2)**

Free Android USB menu remote for **DJI Goggles N3 + original DJI Neo +
DJI FPV Remote Controller 3**. Restores the Manual assignment through the
existing goggles menu, including when the physical 5D button is damaged.
Independent project; not affiliated with DJI. No firmware modification or
permanent setting freeze. Use on the bench, with propellers removed and motors off.

Bezpłatny pilot menu USB dla **DJI Goggles N3 + oryginalnego DJI Neo +
DJI FPV Remote Controller 3**. Przywraca przypisanie Manual przez istniejące
menu gogli, także przy uszkodzonym5D. Niezależny projekt, bez powiązania z DJI.
Nie modyfikuje firmware ani nie zamraża ustawień. Używaj na stole, ze zdjętymi
śmigłami i wyłączonymi silnikami.

## Language / Język

One APK includes both languages. Default: Polish on a phone whose primary
system language is Polish, English otherwise. **Language / Język → System,
English, Polski** lets you choose. Android's installer uses the system language.

Jeden APK zawiera oba języki. Domyślnie: polski dla pierwszego języka systemu
polskiego, angielski dla pozostałych. Wybór: **Language / Język → System,
English, Polski**. Instalator Androida korzysta z języka systemowego.
